# Portfolio UI Redesign — "Quiet Craft"

## Concept

Refined minimalism where **typography is the primary visual element**. Every pixel is intentional. The design feels like opening a beautifully typeset book — warm, measured, and human. No neon, no glassmorphism, no terminal windows, no gradient text, no dot grids. Just precise type, warm color, and breathing space.

**Mood:** A Japanese zen garden meets a Scandinavian design studio. Nature, stillness, precision. Organic warmth without decoration. The peace of a quiet forest clearing — where everything has its place and nothing is多余 (unnecessary).

## Design Decisions

### Typography

| Role | Font | Rationale |
|------|------|-----------|
| Display headings | **Instrument Serif** (keep, use more dramatically) | Elegant editorial serif already loaded — just scale it up massively |
| Body | **Manrope** (keep) | Clean and warm, works well at body sizes |
| Mono/Code | **IBM Plex Mono** (replace JetBrains Mono) | Warmer, more organic feel — less cold/technical, more "workshop notebook" |

Google Fonts link update: swap JetBrains Mono for IBM Plex Mono. Add `Fira Code` as fallback.

### Color Palette

Nature-peace inspired: forest floor, morning mist, moss on stone.

```css
--bg:       #0b0d0b;     /* deep forest black (slightly green-tinted) */
--surface:  #111411;     /* moss-dark elevation */
--border:   #1c201c;     /* fern-shadow borders */
--text:     #e2e0d8;     /* warm stone/parchment cream */
--muted:    #707568;     /* sage gray — like lichen on rock */
--accent:   #7a9e7e;     /* muted sage green — calm, organic, alive */
--accent-dim: #5c7a5f;   /* deeper forest green */
```

The accent evokes moss, fern, and morning dew. It feels peaceful and natural without being cliché "eco green." The overall palette is like looking into a quiet forest at dusk — dark, warm, with living green notes.

### Background

Replace the dot grid with a **CSS noise/grain overlay** using an SVG filter. This adds organic texture and warmth without being distracting. Achieved via:
```css
body::after {
  content: '';
  position: fixed;
  inset: 0;
  background: url("data:image/svg+xml,...") /* inline SVG noise */;
  opacity: 0.03;
  pointer-events: none;
  z-index: 9999;
}
```

## Layout — `index.html`

### 1. Navigation

- Clean horizontal bar: logo left, links right
- **No backdrop blur, no glass** — just transparent, gains a bottom border on scroll
- Logo: IBM Plex Mono, accent color, slight letter-spacing
- Links: Manrope, muted color, 13px, hover to cream
- Scroll behavior: adds `border-bottom: 1px solid var(--border)` after 50px scroll

### 2. Hero Section

Full-viewport, left-aligned with intentional vertical centering.

Structure:
```
[mono label: "Go Backend Developer" — 12px, accent, uppercase, letter-spaced]

[massive serif heading: "Building tools<br>that ship fast"]
  - clamp(3.5rem, 9vw, 7.5rem) — DRAMATICALLY larger than current
  - "ship fast" in italic + accent color
  - line-height: 1.0

[description paragraph — 16px, muted, max-width: 480px]

[action buttons: accent primary + ghost border]

[status line: mono 12px, muted, with pulsing green dot]
```

Animations: Staggered fadeUp (same concept but refined easing: `cubic-bezier(0.22, 1, 0.36, 1)`).

### 3. Tech Stack Section

**Replace card grid with a single horizontal text line.** No cards, no pills.

```
Go · C · C++ · Java · PHP · JavaScript · HTML · CSS · Vue · Wails · Fyne · Git · Docker · Linux · Neovim
```

- IBM Plex Mono, 13px, muted color
- Separator: middle dot (·) with slight spacing
- Wrapped in a flex container with `flex-wrap: wrap` and `gap`
- On hover, individual items change to cream
- Section header: serif h2 + horizontal line (keep existing pattern but refine)

### 4. Projects Section

**Replace card grid with a vertical list.** Each project is a full-width interactive row.

Structure per project:
```
┌─────────────────────────────────────────────────┐
│  ProjectName                          →         │
│  Description text in muted color                │
├─────────────────────────────────────────────────┤
```

- Project name: IBM Plex Mono, 16px, accent color (sage green — living, calm)
- Description: Manrope, 14px, muted
- Arrow: muted, transitions to accent + translates right on hover
- Separator: 1px border-bottom between items (like branches in a row)
- Hover: entire row gets subtle background shift, arrow animates
- Fade-in animation on load (staggered, from GitHub fetch)
- Loading state: mono text "fetching repos" with animated ellipsis

### 5. Footer

- Top border line
- Centered, mono 12px, muted
- Content: `© 2026 Aswanidev VS — Code Build Learn Repeat`

## Custom Interactions

### 1. Scroll Progress Bar
- A 2px accent-colored (sage green) line at the very top of the viewport
- Width = scroll percentage
- Pure CSS + minimal JS (update `--scroll` custom property)

### 2. Scroll Reveal (Intersection Observer)
- Elements with `data-reveal` attribute fade up as they enter viewport
- Staggered delays for children
- Uses `cubic-bezier(0.22, 1, 0.36, 1)` easing — smooth and organic

### 3. Project Row Hover
- Arrow translates 4px right
- Row background shifts to `var(--surface)`
- Left border accent appears (2px)

### 4. Button Hover (Primary)
- Background lightens slightly
- Subtle translateY(-1px)
- No box-shadow (keeps it clean)
